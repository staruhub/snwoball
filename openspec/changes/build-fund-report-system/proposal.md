## Why

基金分析师和投资经理在日常工作中需要对基金产品进行多维度分析，但现有工具固化、无法灵活配置、需要手动整合多个数据源，效率低下。本提案旨在构建一个模块化、可拖拽的基金分析报告系统（Snowball），让用户能够高效地创建、编辑和导出专业分析报告。

## What Changes

### 核心功能模块

#### 1. 用户认证 (user-auth)
- 账号密码登录
- 手机验证码登录
- 企业 SSO 登录
- 忘记密码/密码重置
- JWT Token 管理

#### 2. 工作台首页 (workspace)
- 顶部导航栏（Logo、全局搜索、消息通知、用户头像下拉）
- 快捷入口区（新建报告、从模板创建、导入报告）
- 最近报告列表
- 收藏的模板
- 市场速览（可选）

#### 3. 报告管理中心 (report-management)
- 报告列表页（表格/卡片视图）
- 筛选栏（类型、状态、时间、基金）
- 排序功能
- 批量操作（导出、删除、归档）
- 回收站

#### 4. 模板管理中心 (template-management)
- 系统模板（官方预设）
- 个人模板（用户创建）
- 模板分类（周报/月报/季报/年报/专项）
- 模板预览和使用
- 模板收藏

#### 5. 报告编辑器 (report-editor) - 核心
- **顶部操作栏**：返回、报告名称、保存状态、全局筛选条件、预览/导出/保存按钮
- **全局筛选条件**：基金选择器、日期范围、业绩基准、数据频率、净值类型
- **左侧模块导航**：树形结构、可折叠、搜索功能
- **中间画布区域**：模块卡片、拖拽排序、调整大小
- **右侧配置面板**：全局设置、模块参数配置、全局样式
- **模块操作**：添加、删除、克隆、全屏预览
- **参数锁定机制**：模块参数可锁定/解锁跟随全局

#### 6. 分析模块系统 (analysis-modules)
- **产品信息**：产品表头、基本信息、基金经理、产品要素、费率信息、历史规模
- **基础分析**：
  - 收益统计（年度/月度/季度/滚动收益、净值走势、超额收益）
  - 风险统计（Beta、VaR、波动率、回撤、风险调整收益）
  - 业绩表现（概览表、同类排名、业绩持续性、牛熊市表现）
  - 组合分析（资产配置、行业配置、重仓股票、持仓集中度）
  - 净值归因（Brinson、风格、行业、个股、交易归因）
- **股票策略**：风格分析、因子暴露、选股能力
- **债券策略**：久期分析、信用分析、利率敏感性
- **FOF分析**：子基金配置、策略配置、风格穿透
- **风险监控**：风险仪表盘、风险预警、压力测试、情景分析
- **业绩比较**：多基金对比、与基准对比、竞品分析

#### 7. PDF 导出 (pdf-export)
- 导出配置弹窗
- 支持 PDF 导出（A4纵向/横向）
- 封面页、目录、页码选项
- 导出进度显示
- 导出模板管理

#### 8. 个人中心 (user-settings)
- 个人信息管理
- 账户设置（密码、手机、邮箱）
- 偏好设置（默认基准、日期范围、主题）
- 我的关注（基金关注列表）
- 操作日志

#### 9. 系统管理 (admin-system) - 管理员功能
- 用户管理
- 角色管理
- 模块管理
- 系统模板管理
- 系统配置

#### 10. 帮助中心 (help-center)
- 快速入门
- 指标说明
- 常见问题 FAQ
- 联系客服

### 后续版本功能（不在本期范围）

- **后端**：FastAPI + SQLAlchemy + PostgreSQL + Redis
