## ADDED Requirements

### Requirement: Quick Start Guide

The system SHALL provide quick start guides for new users.

#### Scenario: Create first report guide

- **WHEN** user accesses "创建第一份报告" guide
- **THEN** system displays step-by-step instructions for creating a report

#### Scenario: Add modules guide

- **WHEN** user accesses "添加分析模块" guide
- **THEN** system displays instructions for adding and configuring modules

#### Scenario: Export report guide

- **WHEN** user accesses "导出报告" guide
- **THEN** system displays instructions for exporting reports

#### Scenario: Use template guide

- **WHEN** user accesses "使用模板" guide
- **THEN** system displays instructions for using templates

### Requirement: Indicator Documentation

The system SHALL provide comprehensive indicator documentation.

#### Scenario: Return indicators

- **WHEN** user views return indicators documentation
- **THEN** system displays explanations for: 区间收益, 年化收益, 超额收益, etc.

#### Scenario: Risk indicators

- **WHEN** user views risk indicators documentation
- **THEN** system displays explanations for: 波动率, 最大回撤, VaR, Beta, etc.

#### Scenario: Risk-adjusted return indicators

- **WHEN** user views risk-adjusted indicators documentation
- **THEN** system displays explanations for: 夏普比率, 索提诺比率, 卡玛比率, 信息比率

#### Scenario: Attribution indicators

- **WHEN** user views attribution indicators documentation
- **THEN** system displays explanations for: Brinson归因, 风格归因

#### Scenario: Indicator detail

- **WHEN** user views specific indicator documentation
- **THEN** system shows: 指标名称, 计算公式, 指标说明, 参考标准

### Requirement: FAQ

The system SHALL provide frequently asked questions.

#### Scenario: View FAQ list

- **WHEN** user navigates to FAQ section
- **THEN** system displays categorized list of common questions

#### Scenario: Search FAQ

- **WHEN** user searches in FAQ
- **THEN** system displays matching questions and answers

### Requirement: Customer Support

The system SHALL provide customer support access.

#### Scenario: Contact support

- **WHEN** user clicks "联系客服"
- **THEN** system displays contact options (email, phone, online chat)

#### Scenario: Submit feedback

- **WHEN** user submits feedback
- **THEN** feedback is recorded for product team review
