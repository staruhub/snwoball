## 快速开始

### 登录系统

1. 访问系统登录页面
2. 输入用户名和密码
3. 点击"登录"按钮

支持的登录方式：
- 账号密码登录
- 手机验证码登录（需绑定手机）
- 企业SSO登录（需企业开通）

### 创建第一份报告

1. 登录后进入工作台
2. 点击"新建报告"按钮
3. 在基金选择器中选择要分析的基金
4. 从左侧导航添加分析模块
5. 点击"保存"完成创建

## 工作台

工作台是您登录后的首页，提供快捷入口和常用功能。

### 收藏模板

显示您收藏的常用模板，便于快速使用。

## 报告编辑器

报告编辑器是系统的核心功能，采用三栏布局设计。

### 界面布局

```
┌─────────────────────────────────────────────────┐
│                  顶部操作栏                       │
├─────────────────────────────────────────────────┤
│                 全局筛选条件                      │
├──────────┬──────────────────────┬───────────────┤
│          │                      │               │
│  模块    │       画布区域       │    配置      │
│  导航    │    (报告内容)        │    面板      │
│          │                      │               │
└──────────┴──────────────────────┴───────────────┘
```

### 全局筛选条件

设置影响所有模块的参数：

| 参数 | 说明 |
|------|------|
| 基金 | 选择要分析的基金产品 |
| 日期范围 | 设置分析的时间区间 |
| 业绩基准 | 选择对比基准（如沪深300） |
| 数据频率 | 日/周/月频数据 |
| 净值类型 | 复权/非复权净值 |

### 左侧模块导航

浏览和添加分析模块：

1. 按分类浏览所有可用模块
2. 点击分类名展开/折叠
3. 双击模块名称添加到画布
4. 使用搜索框快速查找

### 中间画布区域

管理报告中的模块：

- **拖拽排序**：按住标题栏拖动调整顺序
- **调整大小**：拖动卡片边缘改变尺寸
- **选中编辑**：点击卡片进入编辑模式
- **操作菜单**：更多操作（删除、克隆、全屏）

### 右侧配置面板

配置全局和模块参数：

**全局设置标签页**：
- 全局样式配置（主题、字体等）

**模块设置标签页**（选中模块时显示）：
- 模块特定参数
- 参数锁定控制

### 参数锁定机制

- 🔓 解锁状态：参数跟随全局设置变化
- 🔒 锁定状态：参数独立，不受全局影响

点击锁图标切换状态。

## 分析模块

系统提供丰富的分析模块，按功能分类。

### 产品信息

- **产品表头**：基金名称、代码等基本信息
- **基本信息**：类型、成立日期、托管人等
- **基金经理**：经理信息及任职情况
- **产品要素**：投资目标、投资范围
- **费率信息**：各类费率说明
- **历史规模**：规模变化趋势

### 收益统计

- **净值走势图**：净值与基准对比
- **区间收益**：不同时段收益率
- **年度/月度收益**：收益率统计
- **滚动收益**：滚动窗口收益分析
- **超额收益**：相对基准的超额

### 风险统计

- **滚动波动率**：波动率走势
- **最大回撤**：历史最大回撤
- **动态回撤**：回撤走势图
- **风险调整收益**：夏普、索提诺等

### 业绩表现

- **业绩概览表**：综合指标汇总
- **同类排名**：在同类中的排名

### 组合分析

- **资产配置**：股债现金比例
- **行业配置**：行业分布
- **重仓股票**：前十大重仓

## 模板管理

### 使用模板创建报告

1. 点击"从模板创建"
2. 浏览系统模板或个人模板
3. 预览模板结构
4. 点击"使用此模板"
5. 选择基金开始编辑

### 保存为模板

1. 打开已完成的报告
2. 点击右上角菜单
3. 选择"保存为模板"
4. 填写模板信息
5. 确认保存

### 模板分类

- **系统模板**：官方预设模板
- **个人模板**：用户自建模板

## 导出功能

### 导出为PDF

1. 完成报告编辑
2. 点击"导出"按钮
3. 配置导出选项：
   - 纸张方向（纵向/横向）
   - 是否包含封面
   - 是否生成目录
   - 是否显示页码
4. 点击"开始导出"
5. 等待生成完成后下载

### 导出配置说明

| 选项 | 说明 |
|------|------|
| A4纵向 | 适合文字较多的报告 |
| A4横向 | 适合图表较多的报告 |
| 封面页 | 包含报告标题和基本信息 |
| 目录 | 自动生成模块目录 |
| 页码 | 在页脚显示页码 |

## 常见问题

### Q: 报告会自动保存吗？

A: 是的，系统每60秒自动保存一次。也可以随时手动保存。

### Q: 如何恢复删除的报告？

A: 进入报告管理→回收站，选择要恢复的报告点击"还原"。报告在回收站保留30天。

### Q: 数据多久更新？

A: 净值数据每个交易日晚间更新，持仓数据按季度披露后更新。

### Q: 如何联系客服？

A: 进入帮助中心→联系客服，可通过邮件、电话或在线客服获取帮助。
